# Ростовые персонажи и позы

Движок уже умеет показывать персонажей в полный рост, с позами и жестами. Пока для персонажа нет
ростовых кадров, он остаётся бюстом, как сейчас, — ничего не ломается. Включается это для каждого персонажа
отдельно: стоит положить его кадры и прогнать конвейер.

## Что нужно нарисовать

Для каждого персонажа:

- **поза `idle`** (основная, руки опущены) — по одному кадру на каждую эмоцию, которая есть у бюста
  (`neutral`, `smile`, `sad`, `angry`, `fear`, `shock`, `closed` и т. д., список — в `assets/portraits/manifest.json`);
- **2–4 дополнительные позы** — например `crossed` (руки скрещены), `chin` (рука у подбородка), `point` (указывает),
  `phone` (телефон у уха); в каждой позе хватит 2–4 главных эмоций (остальные возьмутся похожие);
- **по желанию — варианты для анимации**: тот же кадр, где *только* открыт рот (`_talk`) или *только* закрыты глаза (`_blink`).
  Конвейер сам найдёт, чем они отличаются, и вырежет накладку.

Требования к кадру: вертикальный, человек целиком от макушки до ступней, вид спереди или в три четверти,
нейтральный однотонный фон (вырежется автоматически) или прозрачный PNG. Размер — от 900×1800.

## Как сохранить лица один в один

Лица у текущих бюстов удачные, их нельзя «перегенерировать» — получится другой человек. Порядок:

1. **Тело — дорисовкой вниз (outpaint).** Взять кадр бюста `assets/portraits/<id>_<expr>.webp`
   (или исходник из `art-src/panels`), положить в верх холста 900×1800 и дорисовать **только нижнюю часть**:
   маска outpaint — всё ниже шеи, голова и волосы закрыты от изменений.
   Подсказка для модели (англ.):
   > full body, same character, same outfit continued, standing, arms relaxed at sides, anime visual novel style,
   > soft cinematic rim light, dark rainy cyberpunk palette, consistent lighting with the head, plain dark background
2. **Позы — дорисовкой только рук и корпуса (inpaint).** На готовом ростовом кадре закрасить маской руки/плечи
   и описать жест: `arms crossed`, `hand on chin, thinking`, `pointing forward`, `holding a phone to the ear`.
   Голову и лицо маской **не** трогать.
3. **Эмоции** — голова эмоции переносится на тело позы: кадр эмоции = кадр позы, в который вклеена голова
   нужного бюста (по шее). Это можно сделать в любом редакторе слоями; совпадение по шее — главное.
4. **Рот и глаза для анимации** — копия кадра, где правкой только рта (или только глаз) сделано «открыто» / «закрыто».

## Куда положить и как собрать

```
art-src/poses/<id>/idle/neutral.png
art-src/poses/<id>/idle/neutral_talk.png      (необязательно)
art-src/poses/<id>/idle/neutral_blink.png     (необязательно)
art-src/poses/<id>/idle/smile.png ...
art-src/poses/<id>/crossed/neutral.png ...
```

```bash
python3 tools/art/poses.py <id>     # вырез, раскладка 720×1440, растворение ступней, накладки, manifest.json
npm run build && npm run apk
```

После этого персонаж в игре стоит в полный рост (ноги у нижнего края, голова над окном текста; три места на сцене
без пересечений), дышит и слегка переносит вес (на телефонах — без этой анимации, ради плавности), кивает при смене
эмоции. Бюсты этого персонажа заменяются ростовыми кадрами позы `idle`.

## Позы в сценарии

Тег ink: `@ # pose: voron crossed` — фигура плавно меняет позу (с лёгким акцентом-движением).
`@ # pose: voron idle` — вернуть основную. Если позы нет в манифесте, тег ничего не делает.

Особый случай: «пустой белый взгляд» героини рисуется по координатам глаз бюста (`GLITCH_EYES` в `src/engine/stage.ts`).
Если героиня станет ростовой, координаты нужно поправить под новый кадр.
