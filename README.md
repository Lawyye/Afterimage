# AFTERIMAGE

Кинематографическая интерактивная детективная новелла. Киберпанк, психологический триллер, мистерия.
Около 25–30 минут на первое прохождение, 6 концовок (одна — скрытая).

> Порт-Ирис. Каждый житель носит за ухом «Свидетеля» — имплант, который помнит последние шесть часов.
> После смерти запись замирает. Мёртвые не лгут.
> Этой ночью последний взгляд жертвы покажет ваше лицо.

⚠ **Без спойлеров.** Сюжет, развязка и условия концовок описаны только во внутреннем файле
`story/_SPOILERS_DESIGN.md` и в сценарии `story/*.ink`. Не открывайте папку `story/`, пока не пройдёте игру.

## Как запустить

### Android (проще всего)

1. Установите на телефон `Afterimage.apk` (≈13 МБ). Готовые сборки в репозитории не хранятся:
   APK собирается командой `npm run apk` (см. «Для разработки»).
2. Откройте файл и разрешите установку из этого источника, если телефон спросит
   («Установка неизвестных приложений» для браузера или файлового менеджера).
3. Запустите «Afterimage» с рабочего стола. Игра сразу открывается на весь экран и горизонтально,
   работает без интернета; кнопка «Назад» — пауза и закрытие окон, на титульном экране — выход.

Требуется Android 7.0 или новее с обновлённым Android System WebView.

### Браузер (компьютер или телефон)

Готовая игра — **один файл** `index.html` (≈17 МБ: движок, сценарий, шрифты и все иллюстрации внутри).

1. Возьмите файл: `npm run build` создаёт `dist/index.html`, а каждая проверка GitHub Actions
   прикладывает его к запуску (вкладка Actions → последний запуск → Artifacts → `afterimage-web`).
   Одного этого файла достаточно, папки рядом не нужны.
2. Откройте его в браузере: Chrome, Edge, Firefox, Safari, Samsung Internet — актуальные версии.
3. Нажмите на экран — так браузер разрешит звук. Лучше всего — в наушниках и на весь экран
   (кнопка ⛶ в правом верхнем углу, клавиша `F` или пункт «Полный экран» в меню).

Игра работает без интернета. На телефоне играйте в горизонтальной ориентации:
в вертикальной игра попросит повернуть экран и предложит кнопку «Полный экран и поворот».
На маленьких экранах интерфейс автоматически укрупняется, чтобы текст и кнопки было удобно читать и нажимать.

## Управление

| Действие | Клавиши / мышь |
|---|---|
| Дальше | клик, `Пробел`, `Enter` |
| Выбор ответа | клик или цифры `1`–`4` |
| Осмотр места | клик по отмеченным зонам; `Tab`/стрелки + `Enter` |
| Журнал улик | `J` |
| Доска расследования | `B` |
| Журнал реплик (вернуться к прошлым диалогам) | `L` или колесо мыши вверх |
| Авточтение / пропуск прочитанного | `A` / `S` (или удерживать `Ctrl`) |
| Назад к прошлой реплике | `Backspace` / `PageUp` или кнопка «◂ Назад» |
| Скрыть интерфейс (рассмотреть сцену) | `H` или кнопка «Скрыть»; любое касание — вернуть |
| Быстрое сохранение / загрузка | `F5` / `F9` или кнопки «Б.СОХР» / «Б.ЗАГР» |
| Пауза, сохранение, загрузка, настройки | `Esc` |
| Полный экран | `F` или кнопка ⛶ |

На телефоне всё управляется касаниями: касание сцены — дальше, касание варианта — выбор.
Над окном текста — кнопки «Назад», «Лог», «Авто», «Пропуск», «Скрыть»; быстрое сохранение и загрузка — в меню паузы.

Решения в игре необратимы — как в жизни. Кнопка «Назад» отматывает реплики до последнего принятого решения
(отматывать и решения можно, включив это в настройках → «Текст»). Перечитать прошлые реплики можно в журнале реплик,
а к прошлым моментам — через сохранения (5 слотов, быстрое сохранение и автосохранение в начале каждой главы)
или через пункт «Главы» в главном меню: начало каждой главы, до которой вы дошли, запоминается.
Некоторые решения нужно принимать на время; таймеры можно отключить в настройках.

## Что внутри

- **Сюжет**: пролог и четыре главы, сквозная система флагов и отношений, отложенные последствия,
  альтернативные пути расследования, заблокированные варианты ответов, которые открываются выводами.
- **Расследование**: осмотр мест преступления, документы, архив камеры наблюдения с прокруткой,
  доска расследования (связывание улик нитью), журнал улик и досье персонажей.
- **Хроника решений** в духе блок-схемы: после каждой главы видно, что вы выбрали,
  что открыли в прошлых прохождениях и сколько ещё осталось «???».
- **Персонажи**: семь героев с наборами эмоций, морганием и анимацией речи. Пока вы не встретили
  человека, в досье он — чёрный силуэт со знаком «?», а незнакомец, который ещё не представился, говорит под именем «???».
- **Галерея**: увиденные места, иллюстрации и эмоции персонажей открываются в главном меню.
- **Термины**: вкладка журнала с понятными объяснениями слов мира («Свидетель», послеобраз, сверка, чистка…) — открываются по мере того, как встречаются в истории.
- **Звук**: вся музыка и звуки синтезируются в реальном времени (Web Audio) —
  дождь, город, гул машин, радиопомехи, генеративный саундтрек с уровнями напряжения.
- **Озвучка**: голосом говорят ОРФЕЙ (аналитическая система — синтезированный голос ей по роли),
  объявления терминалов, диктор вступления, трейлера и заставок глав. Громкость — «Настройки → Звук → Озвучка»,
  в журнале реплик озвученную строку можно переслушать (▶).
- **Кат-сцены**: озвученное вступление с движением камеры, дождём и титрами; трейлер в главном меню
  (без спойлеров — только завязка). Пропуск — кнопкой «Пропустить», Enter или Esc.
- **Режиссура**: смена планов, «дыхание» камеры, вспышки, глитчи, режим чтения памяти, летербокс,
  титры глав.
- **Доступность**: отключаемые вспышки/глитчи и тряска, регулировка шума плёнки, скорости текста, таймеров,
  прозрачности и размера текста; на телефоне — вибрация в напряжённые моменты (отключается в настройках).

## Для разработки

```bash
npm install
npm run build        # сборка: dist/index.html (автономный) и build-artifact/ (веб-версия)
npm run watch        # пересборка при изменениях
npm run test:story   # симулятор: тысячи случайных прохождений сценария (все концовки, нет тупиков)
npm run test:e2e     # сквозное прохождение в браузере через интерфейс (Playwright)
npm run test:ui      # интерфейс на 1280×720, 1920×1080, 800×360 и 360×800 (мышь и касания)
npm run test:features # досье, «???», «Назад», быстрые сохранения, скрытие интерфейса, главы, галерея
npm run test:perf    # плавность на телефонном экране с реальной плотностью пикселей (кадры, слои, растеризация)
npm run test:review  # регрессии: уход портрета, стороны, дождь 30 к/с, гонка фонов, таймер на паузе, позы
npm run apk          # сборка dist/Afterimage.apk (нужны пакеты aapt apksigner zipalign dalvik-exchange android-sdk-platform-23 и JDK)
                     # и ключ подписи: tools/android/release.keystore + release.pass, в git не хранятся;
                     # новый ключ — AFTERIMAGE_NEW_KEY=1 npm run apk (такой APK не обновит игру, подписанную другим ключом)
npm run typecheck
node tools/storycheck.mjs <папка-копия-сценария>  # после правки текста: структура сценария не изменилась
```

При каждой отправке в репозиторий GitHub Actions проверяет типы, сценарий (симулятор прохождений), сборку
и браузерные тесты (интерфейс, функции, регрессии, точки осмотра, сквозное прохождение) — `.github/workflows/ci.yml`.
Папка `dist/` и ключи подписи в git не попадают (`.gitignore`).

Сохранения помечаются версией сценария. Если текст игры обновился, старое сохранение загружается в начало той же главы: все решения, улики и отношения переносятся.

Структура:

```
src/engine/   движок: сцена, диалоги, выборы, звук, эффекты, сохранения
src/ui/       интерфейс: меню, журнал, доска, документы, камеры, хроника
src/data/     данные: улики, выводы, зоны осмотра, документы, концовки
story/        сценарий на языке ink (⚠ спойлеры)
assets/       готовые иллюстрации (WebP)
art-src/      исходные листы эмоций и фоны
tools/        сборка и обработка иллюстраций (tools/art/*.py)
tests/        симулятор сюжета и браузерные тесты
```

Сценарий написан на [ink](https://github.com/inkle/ink) и исполняется движком inkjs (MIT).
Шрифты: Tektur, IBM Plex Sans/Mono, PT Serif, Caveat — SIL Open Font License.
Иллюстрации персонажей и локаций созданы генеративными моделями изображений по авторскому арт-дирекшну
и обработаны конвейером `tools/art/`: нарезка эмоций, нейросетевой апскейл (Real-ESRGAN anime, ncnn),
вырезание персонажей (ISNet-anime, onnxruntime), вклейки для моргания и речи.

### Озвучка и трейлер

```bash
pip install -r tools/voice/requirements.txt
bash tools/voice/fetch-voices.sh   # голоса Piper denis и dmitri (CC0) → .art-cache/tts/voices
npm run voice     # собрать все озвучиваемые реплики (симулятор + кат-сцены + главы) и озвучить новые/изменённые
npm run build
npm run trailer   # записать трейлер в dist/Afterimage-trailer.mp4 (нужен ffmpeg)
```

Текст для синтеза нормализуется (время, числа, инициалы, ударения в именах через фонемы — `tools/voice/gen.py`).
Каждая фраза синтезируется в нескольких дублях, и остаётся самый разборчивый: его определяет распознавание речи
(Whisper small) — средняя дословность около 0.96. Озвучка встроена в файл игры (≈3 МБ), ключ фразы — хеш «роль:текст»,
поэтому после правки текста реплики её нужно переозвучить (`npm run voice`); без файла реплика просто идёт без голоса.

Голоса: ОРФЕЙ и объявления терминалов — Piper `ru_RU-dmitri-medium` и `ru_RU-denis-medium` (датасеты OHF-Voice, лицензия CC0).
Диктор вступления, трейлера и заставок глав — ElevenLabs, голос «Maxim — Deep Russian Narrator», модель eleven_v4
(бесплатный тариф ElevenLabs: некоммерческое использование с упоминанием ElevenLabs). Тексты для синтеза с ударениями —
`art-src/voice/narrator/prompts.json`, дубли — `art-src/voice/narrator/takes/`; генератор берёт самый разборчивый,
а для фраз без записи синтезирует голос Piper.

### Ростовые персонажи и позы

Все семь персонажей стоят в сцене в рост: тело дорисовано генеративной моделью от их бюста
(Ворон и Ева — Nano Banana через Figma Weave, остальные пятеро — модель xAI через Grok), поверх посажена настоящая голова
с эмоциями, морганием и речью; сборка — `tools/art/outpaint.py` (исходники в `art-src/outpaint/`).
Движок поддерживает и позы (тег сценария `pose: <id> <поза>`), но у всех поз одна рамка головы, поэтому новые позы рук
пока не добавлены. Как нарисовать и подключить кадры — [docs/ART_POSES.md](docs/ART_POSES.md),
сборка: `python3 tools/art/poses.py <id>`.

### Пересборка портретов

```bash
pip install ncnn onnxruntime pillow numpy
# модели в .art-cache/models/: realesrgan-x4plus-anime.{param,bin} (релиз realesrgan-ncnn-vulkan-20220424)
# и isnet-anime.onnx (релизы danielgatis/rembg)
python3 tools/art/slice_sheets.py   # листы эмоций → кадры
python3 tools/art/portraits.py      # апскейл, маски, накладки → assets/portraits
python3 tools/art/backgrounds.py    # фоны → assets/bg
npm run build
```
