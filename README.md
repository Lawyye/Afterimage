# ПОСЛЕОБРАЗ / AFTERIMAGE

Кинематографическая интерактивная детективная новелла. Киберпанк, психологический триллер, мистерия.
Около 25–30 минут на первое прохождение, 6 концовок (одна — скрытая).

> Порт-Ирис. Каждый житель носит за ухом «Свидетеля» — имплант, который помнит последние шесть часов.
> После смерти запись замирает. Мёртвые не лгут.
> Этой ночью последний взгляд жертвы покажет ваше лицо.

⚠ **Без спойлеров.** Сюжет, развязка и условия концовок описаны только во внутреннем файле
`story/_SPOILERS_DESIGN.md` и в сценарии `story/*.ink`. Не открывайте папку `story/`, пока не пройдёте игру.

## Как запустить

Готовая игра — **один файл** `dist/index.html` (≈14 МБ: движок, сценарий, шрифты и все иллюстрации внутри).

1. Скачайте `dist/index.html` (одного этого файла достаточно, папки рядом не нужны).
2. Откройте его в браузере: Chrome, Edge, Firefox, Safari, Samsung Internet — актуальные версии.
3. Нажмите на экран — так браузер разрешит звук. Лучше всего — в наушниках и на весь экран
   (кнопка ⛶ в правом верхнем углу, клавиша `F` или пункт «Полный экран» в меню).

Игра работает без интернета. На телефоне играйте в горизонтальной ориентации:
в вертикальной игра попросит повернуть экран и предложит кнопку «Полный экран и поворот».
На маленьких экранах интерфейс автоматически укрупняется, чтобы текст и кнопки было удобно читать и нажимать.

## Управление

| Действие | Клавиши / мышь |
|---|---|
| Дальше | клик, `Пробел`, `Enter` |
| Выбор ответа | клик или цифры `1`–`4` |
| Осмотр места | клик по отмеченным зонам; `Tab`/стрелки + `Enter` |
| Журнал улик | `J` |
| Доска расследования | `B` |
| Журнал реплик (вернуться к прошлым диалогам) | `L` или колесо мыши вверх |
| Авточтение / пропуск прочитанного | `A` / `S` (или удерживать `Ctrl`) |
| Пауза, сохранение, загрузка, настройки | `Esc` |
| Полный экран | `F` или кнопка ⛶ |

На телефоне всё управляется касаниями: касание сцены — дальше, касание варианта — выбор.

Решения в игре необратимы — как в жизни. Вернуться к прошлым репликам можно через журнал реплик,
а к прошлым моментам — через сохранения (5 слотов + автосохранение в начале каждой главы).
Некоторые решения нужно принимать на время; таймеры можно отключить в настройках.

## Что внутри

- **Сюжет**: пролог и четыре главы, сквозная система флагов и отношений, отложенные последствия,
  альтернативные пути расследования, заблокированные варианты ответов, которые открываются выводами.
- **Расследование**: осмотр мест преступления, документы, архив камеры наблюдения с прокруткой,
  доска расследования (связывание улик нитью), журнал улик и досье персонажей.
- **Хроника решений** в духе блок-схемы: после каждой главы видно, что вы выбрали,
  что открыли в прошлых прохождениях и сколько ещё осталось «???».
- **Персонажи**: семь героев с наборами эмоций, морганием и анимацией речи.
- **Звук**: вся музыка и звуки синтезируются в реальном времени (Web Audio) —
  дождь, город, гул машин, радиопомехи, генеративный саундтрек с уровнями напряжения.
- **Режиссура**: смена планов, «дыхание» камеры, вспышки, глитчи, режим чтения памяти, летербокс,
  титры глав, вступительная заставка.
- **Доступность**: отключаемые вспышки/глитчи и тряска, регулировка шума плёнки, скорости текста, таймеров.

## Для разработки

```bash
npm install
npm run build        # сборка: dist/index.html (автономный) и build-artifact/ (веб-версия)
npm run watch        # пересборка при изменениях
npm run test:story   # симулятор: тысячи случайных прохождений сценария (все концовки, нет тупиков)
npm run test:e2e     # сквозное прохождение в браузере через интерфейс (Playwright)
npm run test:ui      # интерфейс на 1280×720, 1920×1080, 800×360 и 360×800 (мышь и касания)
npm run typecheck
```

Структура:

```
src/engine/   движок: сцена, диалоги, выборы, звук, эффекты, сохранения
src/ui/       интерфейс: меню, журнал, доска, документы, камеры, хроника
src/data/     данные: улики, выводы, зоны осмотра, документы, концовки
story/        сценарий на языке ink (⚠ спойлеры)
assets/       готовые иллюстрации (WebP)
art-src/      исходные листы эмоций и фоны
tools/        сборка и обработка иллюстраций (tools/art/*.py)
tests/        симулятор сюжета и браузерные тесты
```

Сценарий написан на [ink](https://github.com/inkle/ink) и исполняется движком inkjs (MIT).
Шрифты: Tektur, IBM Plex Sans/Mono, PT Serif, Caveat — SIL Open Font License.
Иллюстрации персонажей и локаций созданы генеративными моделями изображений по авторскому арт-дирекшну
и обработаны конвейером `tools/art/`: нарезка эмоций, нейросетевой апскейл (Real-ESRGAN anime, ncnn),
вырезание персонажей (ISNet-anime, onnxruntime), вклейки для моргания и речи.

### Пересборка портретов

```bash
pip install ncnn onnxruntime pillow numpy
# модели в .art-cache/models/: realesrgan-x4plus-anime.{param,bin} (релиз realesrgan-ncnn-vulkan-20220424)
# и isnet-anime.onnx (релизы danielgatis/rembg)
python3 tools/art/slice_sheets.py   # листы эмоций → кадры
python3 tools/art/portraits.py      # апскейл, маски, накладки → assets/portraits
python3 tools/art/backgrounds.py    # фоны → assets/bg
npm run build
```
